# Memory

Notes that carry lessons across tickets. They live in ~/code/ai/memory/. Read only the file or section relevant to the current task.

| File | Use it for |
| --- | --- |
| reusable-heuristics.md | Rules that changed a decision and should apply again. |
| recurring-mistakes.md | Triggers, missed signals, and earlier questions from real failures. |
| review-checklist.md | Selective questions for plans, diffs, and PRs. |
| growth-log.md | Dated evidence, one experiment, and its later result. |
| observability-planning.md | A production signal plan when monitoring can support a decision. |

Update the narrowest relevant file. One case does not need a full copy in heuristics, mistakes, and checklist; link to the named rule where possible. Keep project-specific rules in the repository's own CLAUDE.md.

The starter material is generalized from a colleague's engineering cases. Replace or remove an item when your own evidence does not support it.

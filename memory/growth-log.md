# Growth log

Use this for short, dated learning from work you actually did. Add entries below the template. Distinguish your decisions from teammate or automated changes.

## Entry template

### YYYY-MM-DD — Task or review

- Evidence: link, diff, comment, test result, or observable outcome.
- What went well:
- What should have been stronger:
- Reusable heuristic or review question:
- One experiment for the next similar task:
- Result to check later:
- Follow-up study topic, if needed:

At the next similar task, revisit the same entry and record whether the experiment helped. Promote a rule to reusable-heuristics.md only when the evidence supports using it again.

## Reflection prompts

- What did I catch early that I would have missed before?
- What did I only notice late in the task?
- Which review comment or bug points to a recurring gap?
- What should become a default check in future work?
- Did the previous experiment change my decision or the outcome?
